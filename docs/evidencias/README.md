# Evidencias de ejecucion

Las capturas de esta carpeta corresponden a una ejecucion local del prototipo con
datos sinteticos en una base SQLite temporal. Se tomaron para documentar las
pantallas, no son fotografias de una instalacion Android ni certifican que Azure
estuviera disponible en el momento de la captura.

No se incluyen credenciales, tokens ni datos personales reales.
